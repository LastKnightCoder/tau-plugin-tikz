# TikZ 繪圖

在文件裡撰寫 TikZ 程式碼，直接預覽繪製出的圖形。不用安裝 LaTeX，也不用連網，裝好外掛就能繪圖，畫好的圖還能發佈到部落格。

## 開始使用

1. 在外掛中心安裝「TikZ 繪圖」，再到外掛頁的「已安裝」裡開啟開關，接著點擊外掛頁頂部提示列上的「立即重啟」，重新啟動後即可使用。
2. 在文件裡開啟區塊選單，選擇「TikZ」。
3. 寫好程式碼並點擊「完成」，稍等片刻就能看到圖形。

```tikz
\begin{tikzpicture}
\draw[->] (0,0) -- (2,0);
\draw (0,0) circle (0.5);
\end{tikzpicture}
```

不需要寫 `\documentclass`；直接貼上含 `document` 環境的完整程式碼也可以。也可以請 AI 助手幫你撰寫 TikZ。

## 常見問題

**第一次出圖有點慢？** 首次使用需先載入繪圖引擎，之後會快很多。單張圖最多等待 2 分鐘。

**程式碼寫錯會怎麼樣？** 會提示錯誤位置，同時保留上一次成功繪製的圖形。

**能使用任意 LaTeX 巨集套件嗎？** 不能。僅支援外掛內建的 TikZ 與常用巨集套件，無法另行安裝套件，也不能引用外部檔案。

**停用或解除安裝外掛後，圖會不見嗎？** 不會。程式碼一直儲存在文件中，重新啟用後照常顯示。

**手機上為什麼看不到圖？** 手機版與瀏覽器擴充功能暫時無法顯示 TikZ 圖，但資料不會遺失，回到電腦上即可看到。

## 小提醒

- 開啟、關閉或升級此外掛後，都必須重新啟動 Tau 才會生效，外掛頁會提示「立即重啟」。
- 發佈包含 TikZ 圖的部落格時，需先安裝並啟用此外掛。
